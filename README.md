# HBS Website - Strategy and Homepage Concept

This folder contains the approved planning stage for the new Helvetic Business School WordPress website.

## What is included

- `planning/sitemap.md` - proposed website structure and navigation
- `planning/homepage-design.md` - homepage concept, section order, interaction, and responsive behavior
- `planning/build-plan.md` - phased WordPress implementation plan
- `planning/content-source-register.md` - content rules, verified sources, and items requiring confirmation
- `prototype/index.html` - responsive, animated homepage design prototype

## Preview the homepage prototype

Open `prototype/index.html` in a modern browser. For the most reliable preview, run it through a small local web server or use the preview command provided by your editor.

The prototype is not yet a WordPress theme. It is the design reference that will be translated into the production block theme after approval.

## Confirmed project rules

- HBS is in La Tour-de-Peilz and is currently based on the AUS campus.
- Vevey is not used as the current HBS location.
- No exterior campus photographs are used.
- Interior photographs from the supplied brochure are permitted.
- Website content must come from `hbs.swiss`, the supplied 2025-2026 brochure, or direct HBS corrections.
- Roboto is the primary typeface. Instrument Sans is the proposed premium display typeface.
- Brand colors: `#002c27`, `#005e53`, `#439c9b`, `#f7e7ce`, `#6e2233`.
